# COVID-19 Data Analysis — Exploratory Data Analysis

## Overview
An exploratory data analysis of global COVID-19 data to uncover 
trends in confirmed cases, deaths, death rates, and recovery 
rates across the most affected countries.

## Questions Explored
- How did global COVID-19 confirmed cases grow over time?
- Which countries had the highest total confirmed cases?
- Which countries recorded the highest number of deaths?
- Which of the top 10 countries had the highest death rate?
- Which of the top 10 countries had the highest recovery rate?

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
- covid_19_clean_complete.csv (sourced from Kaggle)
