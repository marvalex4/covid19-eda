# COVID-19 Data Analysis: Exploratory Data Analysis

## Overview
An exploratory data analysis of global COVID-19 data to uncover 
trends in confirmed cases, deaths, death rates, and recovery 
rates across the most affected countries.

## Questions Explored
1. How did global COVID-19 confirmed cases grow over time?
2. Which countries had the highest total confirmed cases?
3. Which countries recorded the highest number of deaths?
4. Which of the top 10 countries had the highest death rate?
5. Which of the top 10 countries had the highest recovery rate?

## Tools Used
1. Python
2. Pandas
3. Matplotlib
4. Seaborn
5. Jupyter Notebook

## Dataset
- covid_19_clean_complete.csv (sourced from Kaggle)
